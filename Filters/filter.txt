! Description: Tracking parameters that the public $removeparam lists miss, found while sharing real links. Only removeparam rules — this list does not block anything.

! Shopee — affiliate/attribution payload on links from the s.shopee.* and shope.ee
! shorteners. AdGuard filter 17 has some of these, but only for shopee.ph, shopee.co.th
! and shopee.co.id; `shopee.*` covers every country domain including .tw.
! Verified: the product page loads identically with all of them stripped.
$removeparam=credential_token,domain=shopee.*
$removeparam=gads_t_sig,domain=shopee.*
$removeparam=mmp_pid,domain=shopee.*
$removeparam=uls_trackid,domain=shopee.*
$removeparam=exp_group,domain=shopee.*
$removeparam=__mobile__,domain=shopee.*
$removeparam=sp_atk,domain=shopee.*
$removeparam=xptdk,domain=shopee.*
$removeparam=publish_id,domain=shopee.*
$removeparam=promotionId,domain=shopee.*
$removeparam=stm_medium,domain=shopee.*
$removeparam=stm_source,domain=shopee.*

! Instagram — share-sheet tracking token on post/reel links. The name is 4 random lowercase
! letters on every share (mdxt, psln, ...) and the value is a base64 id, so it can only be
! matched by shape. Real params such as img_index don't fit it and are kept.
! The two fixed names are for app versions before regex support, which skip the regex line.
||instagram.com^$removeparam=mdxt
||instagram.com^$removeparam=psln
||instagram.com^$removeparam=/^[a-z]{4}=[A-Za-z0-9+\/ ]{12\,}=*\$/
